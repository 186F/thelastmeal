## Purpose

This package develops a versioned, implementation-neutral technical and evidence specification for isolated concurrent independent runs and independent studies that share infrastructure while retaining separate identity, configuration, budget, storage, treatment, and evidence boundaries.

## Explicit exclusions

This package does not authorize:

- implementation or deployment of a parallel laboratory;
- selection of a provider, framework, queue, scheduler, broker, database, object store, serialization format, or deployment topology;
- an experiment, model call, evidence-generating run, or evidence package;
- serial-versus-parallel parity work;
- concurrent decision-making among causally coupled NPCs inside one shared world;
- Work Packages 3–8; or
- alteration or reuse of Milestone 2 evidence as Milestone 3 evidence.
